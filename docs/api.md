# DijiOne API Reference

**Superseded by Phase 2.5.** This document described a single API at
`http://localhost:8000` — DijiOne's API surface is now split across five
backend services, each with its own base URL and its own health endpoint.
See **`docs/platform/service-contracts.md`** for the complete, current
endpoint reference per service (Platform Core, Admin, DijiTalentFlow,
DijiBirthday, DijiSpark), the gateway routing table, and service-to-service
trust boundaries.
