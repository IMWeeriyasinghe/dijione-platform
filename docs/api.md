# DijiOne API Reference

Base URL (local): `http://localhost:8000`. Interactive docs (Swagger UI)
are auto-generated by FastAPI at `/docs` when the server is running.

All endpoints except `/api/health` and `/api/auth/dev-*` require
`Authorization: Bearer <token>`. See `docs/platform/authentication.md`.

## Platform

| Method | Path | Notes |
|---|---|---|
| GET | `/api/health` | No auth. Liveness check. |
| GET | `/api/auth/dev-personas` | No auth. Dev Identity Mode persona list. |
| POST | `/api/auth/dev-login` | `{persona_key}` → `{access_token, user}` |
| GET | `/api/auth/me` | Current user + `module_roles` |
| GET | `/api/modules` | Modules the current user is authorized to see |
| GET | `/api/notifications?unread_only=` | Current user's notifications |
| POST | `/api/notifications/{id}/read` | Mark one notification read |

## Conventions

- Route handlers never query the database directly — see
  `docs/platform/architecture.md`.
- Every response is a Pydantic schema in `app/schemas/*`; provider payloads
  (Lever/HubSpot) are never returned as-is.
- Tenant scoping (`TalentScope`) is resolved once per request in
  `app/api/deps.py` and threaded through every service call — see
  `docs/talent-flow/data-model.md`.
